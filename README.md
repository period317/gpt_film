# 영화계열 수시 실기 조사

## 목표

2024~2026학년도 영화계열 대학·전문대 수시 실기전형을 조사한다. 실제 고사 시행 기준 기간은 주로 2023년 10월부터 2025년 10월까지다.

각 학교마다 아래 항목을 기록한다.

- 모집단위와 수시 전형명
- 실기 시행 여부, 방식, 단계, 시간, 반영비율
- 공식 기출문제 또는 비공식 복기 기출
- 확인 가능한 원문 출처와 확인 상태

## 범위

- 포함: 영화, 영화영상, 영화예술, 영화 연출·제작처럼 영화 창작을 독립 모집단위 또는 분명한 전공 트랙으로 둔 과정
- 제외: 일반 영상콘텐츠, 웹툰, 애니메이션, 미디어, 방송 계열
- 주의: 공식 모집요강을 최종 기준으로 하며, 복기·학원·블로그 기출은 별도 표기한다.

## 보류 후보

영화 단독 전공이 아니거나 방송·연극과 결합되어 있어, 포함 여부를 추후 결정한다.

동국대 영화영상학과, 한양대 연극영화학과 영화전공, 인하대 연극영화학과 연출, 성균관대 연기예술학과 연출, 동의대 영화학과, 한서대 영화예술학과, 청운대 방송영화영상학과, 중부대 연극영화학전공, 극동대 연극영화학과, 중원대 연극영화학과, 예원예대 연극영화전공, 서일대 영화방송제작전공.

## 조사 방식

1. 학년도별 수시모집요강으로 실기 시행과 전형명을 확정한다.
2. 실기 방식·단계·시간·반영비율을 원문에 맞춰 기록한다.
3. 대학 공식 기출을 우선 수집한다.
4. 공식 미공개분은 비공식 복기임을 명확히 구분하고, 원문 URL과 수집일을 남긴다.
